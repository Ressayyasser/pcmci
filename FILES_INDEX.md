## Development Workflow

1. **Data Generation**: Run `scripts/setup_data.py` → creates CSV
2. **ML Pipeline**: Run `scripts/complete_pipeline.py` → creates JSON + PKL
3. **Backend**: Run `python backend/api.py` → serves on :8000
4. **Frontend**: Run `pnpm dev` → serves on :3000
5. **Validation**: Run `python scripts/validate_system.py` → checks health

## Production Deployment

### Frontend
- Build: `pnpm run build` → `.next/`
- Deploy: Vercel (automatic from build)
- Env: `BACKEND_URL=https://api.example.com`

### Backend
- Package: FastAPI + uvicorn
- Dockerfile: Simple Python app
- Deploy: Render, Railway, or Docker
- Health: `GET /health` returns `{"status":"healthy"}`

## Adding New Files

### To Add New Page
1. Create `app/new-page/page.tsx`
2. Create `app/api/new-endpoint/route.ts`
3. Add endpoint to `backend/api.py`
4. Link from home page

### To Add New Analysis
1. Create `backend/src/new_analysis.py`
2. Add to `scripts/complete_pipeline.py`
3. Import in `backend/api.py`
4. Add API endpoint
5. Create frontend page

### To Update Documentation
1. Edit relevant .md file
2. Update this FILES_INDEX.md
3. Update PROJECT_SUMMARY.md if major changes
